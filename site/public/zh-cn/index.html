macOS · restic · 腾讯云 COS

备份你的
Codex 会话。

为本地会话保留加密快照，在浏览器里搜索历史记录，并在需要之前做一次恢复验证。

了解使用流程 ↓

从备份到恢复

run

增量备份

用 restic 将加密增量快照保存到私有 COS 桶。可以手动备份，也可以用 macOS LaunchAgent 定时执行。

browse

搜索会话

按关键词、项目、日期和状态搜索普通或归档会话。可查看渲染后的 Markdown、下载快照附件或导出会话。

restore

校验恢复

将历史快照恢复到空目录，命令行会按快照清单校验恢复文件。

运行环境

macOS、支持 SQLite FTS5 的 Python、restic、zstd 和 GnuPG。云端备份通过 restic 原生 S3 后端接入私有腾讯云 COS 桶，本地恢复演练使用合成数据。
