备份你的
Codex 会话。

为本地会话保留加密快照，在浏览器里搜索历史记录，并在需要之前做一次恢复验证。

了解使用流程 ↓

从备份到恢复

run

增量备份

用 restic 将加密增量快照保存到私有 COS 桶。可以手动备份，也可以用 macOS LaunchAgent 定时执行。

browse

搜索会话

按关键词、项目、日期和状态搜索普通或归档会话，也可以将会话导出为 Markdown。

restore

校验恢复

将历史快照恢复到空目录，命令行会按快照清单校验恢复文件。

发布状态

首个公开版本 v0.1.0 待发布。发布后可在 GitHub 查看源码和下载版本。

运行环境

macOS、支持 SQLite FTS5 的 Python、restic、rclone、zstd 和 GnuPG。云端备份需要私有腾讯云 COS 桶，本地恢复演练使用合成数据。
