From snapshot to recovery

run

Back up

Save incremental, restic-encrypted snapshots to a private COS bucket. Run on demand or schedule backups with a macOS LaunchAgent.

browse

Find a chat

Search active and archived conversations by keyword, project, date, or status. Read rendered Markdown, download snapshot attachments, or export the conversation.

restore

Restore and verify

Restore an earlier snapshot into an empty directory. The CLI checks file contents against the snapshot manifest.

What you’ll need

macOS, Python with SQLite FTS5, restic, zstd, and GnuPG. Cloud backups use restic’s native S3 backend with a private Tencent Cloud COS bucket. The local recovery drill uses synthetic data.
